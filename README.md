# barber-booking-site

Public website for the Barber Booking Bot.

This site provides:

- A basic homepage
- Privacy Policy
- Terms of Service

The site is used for Google OAuth branding and consent requirements for the Barber Booking Bot.

## Pages

- `index.html`
- `privacy.html`
- `terms.html`

The bot itself is hosted separately and is not part of this repository.
